## 1. 定位

MyNet 星图是 cloudflaremyapp 创意清单中「数字生态花园」的直接实现，同时兼顾「个人属性知识图谱」与「简易项目管理与运维中心」（见创意星域 `i_garden`、`i_graph`、`i_ops`）。内容按「星域 → 星系 → 节点 / 属性」组织：

| 概念 | 原型中的对应 |
| --- | --- |
| 星域 | 一个管理方向：技能 `skill`、创意 `idea`、资源 `res`、项目 `proj` |
| 星系 | 一个根节点及其全部隶属后代 |
| 节点 | `state:'node'` 的要素，可拥有属性与子节点，可作为关联目标 |
| 属性 | `state:'attr'` 的要素，附着在所属节点上，不能拥有下级 |
| 隶属 | 要素的 `parent`，唯一，决定结构 |
| 非隶属关系 | `relations` 中的 `{from,type,to}`，不改变结构 |

## 3. 运行

```bash
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/starmap.html` 或 `manage.html`。直接双击 HTML 也能运行，但不同浏览器对 `file://` 页面之间是否共享本地存储不一致，推荐用本地服务。

## 4. 共享数据层（data.js）

```text
window.MyNet = {
  KEY,          // 本地存储键，当前 'mynet.data.v3'
  defaults(),   // 返回初始数据的深拷贝（补齐关系 id 与 fn）
  load(),       // 读本地存储；没有或结构不对时返回 defaults()
  save(data),   // 写本地存储
  reset(),      // 删除本地存储并返回 defaults()
  uid(prefix),  // 生成新要素 / 关系 id
  PALETTE       // 12 种星系配色，两页共用
}
```

- 读写流程：管理台每次修改后 `save`；星图页启动时 `load`。另一个标签页保存时，星图页通过 `storage` 事件提示「刷新星图」。
- `withIds()`：给关系补 `id`（`<星域>_r<序号>`）；给缺少 `fn` 的要素按 `FN` 补齐，不覆盖已有内容。
- 版本：两页以 `data.js?v=2026-11-02e` 引用数据文件。**每次修改 data.js 后，两页的 `?v=` 都要改成新值**，否则浏览器可能继续用缓存。
- 存储键：只有初始数据发生需要立即生效的结构性变化时才升级 `KEY`（v1 演示数据 → v2 真实数据 → v3 补充创意清单）。升级后旧键数据不再读取但不删除；未升级时，用户本地已保存的数据优先于新的初始数据。
- 界面状态（面板收起、沉浸模式）另存于 `starmap.ui`。

## 5. 星图页

### 5.1 三个层级与切换

| 层级 | `S.mode` | 显示 | 进入方式 |
| --- | --- | --- | --- |
| 顶级总览 | `universe` | 四个星域，各自的星系缩微 | 启动默认；点击左上角 STARMAP；星团总览按 Esc |
| 星团总览 | `overview` | 一个星域的全部星系 | 顶级总览双击星域；左上星域按钮 |
| 焦点星图 | `focus` | 以焦点为中心、按距离展开的节点与关系 | 双击星系 / 星上的点；搜索结果；管理台「在星图中查看」 |

四个星域放在同一张世界平面上（`initPacks` 把各星域的星系平移到半径 `Rc = 最大星域范围 × 2.05` 的圆上），所以层级切换是**连续的相机飞行**，不是换页：

| 过渡 | `trans.kind` | 时长 | 做法 |
| --- | --- | --- | --- |
| 顶级 → 星团 | `down` | 1.9 s | 相机飞向该星域；顶级装饰先退场，星团标签后进场 |
| 星团 → 顶级 | `up` | 1.9 s | 反向 |
| 星团 → 焦点 | `in` | 1.6 s | 缩微星体原地展开到距离环；范围内其他星系的节点从各自星系飞来；卫星渐变为行星 |
| 焦点 → 星团 | `out` | 1.3 s | 星体飞回各自星系的缩微位置并缩小 |

从焦点直接回顶级时，先执行 `out` 再接 `up`（`trans.next`）。

### 5.2 视觉语言

| 层级 | 元素 | 表示 |
| --- | --- | --- |
| 顶级 | 星域 | 带刻度的彩色虚线圆环 + 背景光晕；中心虚线只表示「同属总览」，不是关联 |
| 星团 | 星系 | 螺旋星尘盘（装饰，规模随要素数）；中心恒星 = 根节点；层级轨道上的**明亮卫星** = 非根节点（最多 3 级，展示节点超过 30 个时减少层级，不显示名称） |
| 星团 | 跨星系关联 | 拱形流动虚线，按「起点星系 → 终点星系」汇总，线宽随条数，标签列出类型与次数 |
| 焦点 | 根节点 | 恒星：双层日冕、横向镜头光、炽热内核 |
| 焦点 | 节点 | 气态行星：带状纹理、明暗、大气辉光 |
| 焦点 | 属性 | 卫星：在倾斜轨道上环绕所属节点，带尾迹；与所属节点同距离 |
| 焦点 | 隶属 | 直线光束 + 菱形标记 |
| 焦点 | 非隶属关系 | 向上拱起的彩色流动虚线 + 箭头 + 类型标签；起点有圈 = 来自具体属性，起点贴星体 = 来自节点整体 |
| 焦点 | 其他 | 投影线与地面标记（星体在平面上的位置）；距离环 D1…Dn 与雷达扫描；`+N ›` = 范围外仍有相邻节点 |
| 所有 | 功能文字 | 星体下方第三行显示 `fn`（普通星体截断，焦点 / 悬停 / 选中显示全文）；星团总览在星系名下显示根节点 `fn` |

### 5.3 焦点距离（REQUIREMENTS「焦点与距离范围」）

- 只在节点之间计算距离：隶属边、非隶属边各 +1；属性发出的关系视为从其所属节点发出（属性距离 0）。
- 不分方向、取最短路径（BFS）；范围 R 显示距离 ≤ R 的节点及其属性，R 取 1–5。
- 已显示节点之间的已有关系全部显示；范围外的相邻数量以 `+N ›` 提示。
- 跨星系的关系同样计入距离，所以焦点视图可能包含其他星系的节点（不跨星域）。

### 5.4 布局与相机

- 焦点布局：力导向（互斥、隶属 / 关系弹簧）+ 同环切向推开 + 位置约束把节点收拢到 `距离 × GAP(250)` 的环上，带冷却。
- 星团布局：星系初始排成圆环，互斥 + 跨星系关联拉近，迭代 600 次。
- 投影：世界平面绕竖轴自转（`yaw`）并俯仰（`pitch`，默认 0.95 rad）后做透视；透视强度按屏幕尺度计算，远景与近景一致。
- 取景：`autoCam` 以目标视角投影包围点、迭代求缩放，并避开展开的面板（`viewBox()`）；平移后停止自动跟随，「重置视角」恢复。

### 5.5 交互

| 操作 | 作用 |
| --- | --- |
| 单击 | 选中，右侧信息面板显示详情 |
| 双击 | 顶级：进入星域；星团：进入星系；焦点：设为焦点（属性则聚焦所属节点） |
| 拖拽 / 右键或 Shift 拖拽 / 滚轮 | 旋转视角 / 平移 / 缩放 |
| `+` `-` | 调整焦点范围 |
| `Esc` | 返回上一层 |
| `H` | 沉浸模式开关 |
| `F` | 把选中的要素设为焦点 |

- 工具栏：属性标签、关系标签、功能文字、流动动画、自转、重置视角、沉浸。
- 每个面板（顶栏、搜索 / 星系列表、信息、图例）都有独立的收起按钮；沉浸模式统一隐藏，只留左上「上一层」、右上「退出沉浸」和底部可点击的位置路径。

## 6. 管理台

三栏：结构树（可折叠，「＋ 根节点」新建星系）· 表格（要素 / 关系两个标签页，搜索、状态与星系筛选；列名随星域模板）· 编辑器（名称、功能、说明、隶属、属性、子节点、关系）。

| 操作 | 规则（对应验收标准） |
| --- | --- |
| 新建根节点 | 形成新星系（AC01） |
| 改隶属 | 下拉框排除自身与后代，提交前再次校验，禁止成环（AC02、AC03）；目标是属性时先升格；根节点并入其他星系时提示「星系合并」 |
| 添加属性 / 子节点 | 当前要素是属性时先自动升格，身份与原隶属不变（AC05） |
| 建立关系 | 目标是属性时自动升格，不复制对象（AC06）；起点可以是属性且保持属性（AC07）；同一起点、类型、目标不重复；目标限于同一星域 |
| 删除关系 | 直接删除 |
| 删除要素 | 只允许没有下级、没有关联的要素（删除 / 回收站 / 撤销规则尚未定义） |
| 恢复初始数据 | 清除本地存储，回到 data.js |

每次自动升格都会弹出说明。降格、批量编辑、导入导出未实现。

## 7. 两个页面之间的通道

| 方向 | 入口 | 携带的上下文 |
| --- | --- | --- |
| 星图 → 管理台 | 右上「▤ 管理」；信息面板「✎ 编辑」「▤ 管理」 | 星域、选中要素 |
| 管理台 → 星图 | 右上「◉ 星图」；每行 ◎；编辑器「在星图中查看」；左上 STARMAP（回顶级） | 星域、焦点（属性取所属节点）、选中要素 |

| 页面 | 参数 |
| --- | --- |
| `starmap.html#…` | `d` 星域、`f` 焦点节点、`r` 范围、`s` 选中要素；无参数 = 顶级总览 |
| `manage.html#…` | `d` 星域或 `all`、`s` 选中要素、`tab=rel` 关系表、`q` 搜索词 |

## 8. 性能

- 星尘按 4 档颜色 × 2 档透明度分桶，用 `Path2D` 批量填充；远景按屏幕尺寸抽稀；每个星系粒子上限 1500。
- 实测（1440×860，DPR 1.5，预览面板）：顶级总览约 12 ms / 帧，12 个星系的项目星团约 9 ms，15 个星系的创意星团约 17 ms。
- 星系超过 8 个时，统计行只在悬停 / 选中时显示，避免文字重叠。

## 9. 已知限制与未定事项

- 跨星域参照未定义：创意与项目之间的联系以属性文字记录（如 `p_mynet_idea`），不画线。
- 删除 / 回收站 / 撤销 / 降格、人际关系星域模板未定义（需求「后续实现边界」）。
- 数据只存于浏览器本地；没有服务端、同步、多用户、导入导出。
- 只在 Chromium 内核的预览面板中验证过；Firefox / Safari、触屏手势未验证。
- 手机宽度（≤ 860 px）仅做了基本排版，未细调。
