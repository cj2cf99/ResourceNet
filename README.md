# MyNet 星图

依据 [需求](REQUIREMENTS.md) 与 [原型设计](docs/DESIGN.md) 开发的独立本地应用。保留星图与管理台两个页面、四类应用模板、单一隶属、多关系、属性自动升格和焦点距离探索。

审核入口：[当前开发版本审核说明](DEVELOPMENT_REVIEW.md)。架构、数据库、接口、前后端规则和失败处理见 [开发设计与实现说明](docs/IMPLEMENTATION.md)，当前代码摘要见 [CODE_BASELINE.json](docs/CODE_BASELINE.json)。

## 启动

安装 Node.js 24 或更新版本，应用运行无第三方依赖，无需 `npm install`。浏览器回归另需 Playwright 与可用 Chromium。

```powershell
npm start
```

打开 `http://127.0.0.1:8765/`（星图），或 `http://127.0.0.1:8765/manage.html`（管理台）。仅监听本机回环地址；当前是供本机个人使用的版本，未部署或集成 Cloudflare，未实现远程身份认证。

可通过 `PORT` 改端口，通过 `MYNET_DB` 指定独立 SQLite 文件。默认数据库为 `.local/mynet.sqlite`，首次启动由 `data.js` 初始化。以后启动始终使用数据库已有内容，修改初始数据不会覆盖已有数据库。

## 保存与旧数据

管理台字段失焦后串行写入 SQLite，成功后显示“已保存”。保存不重绘正在编辑的输入框。另一个页面抢先保存时会拒绝旧版本；失败编辑保持在页面及本标签页草稿中，可导出并在刷新后恢复。草稿恢复沿用旧版本，不自动覆盖别人内容，冲突需对照最新内容整理。请求有超时及相同请求 ID 的有限重试。

浏览器原有的 `mynet.data.v3` 数据不会自动覆盖数据库。若检测到未导入的旧版内容，管理台提供导入按钮，确认后写入数据库并记录内容指纹，相同旧内容不再提示导入；原旧存储保留。内容改变会重新成为导入候选。

其他页面保存后，可见页面约每 10 秒查询一次轻量版本接口并提示刷新。尚未失焦的输入框内容尚未提交，也没有进入快照草稿；切换页面或刷新前应先让输入框失焦并确认“已保存”。草稿位于浏览器本机、未加密；浏览器禁用或清除站点存储会影响恢复。

## 备份与恢复

管理台的“导出备份”下载数据库当前内容及版本。建议在恢复初始数据或导入旧编辑前先导出。

服务运行时，可用以下命令恢复导出的备份；恢复会替换当前内容，同时保留替换前的数据库快照：

```powershell
node tools/restore-data.mjs backup.json
```

非默认端口可在命令末尾加端口号。完整数据库离线备份应先停止服务，再复制 `.local` 目录；不要在运行期间只复制 SQLite 主文件。历史默认保留最近 200 个版本，可用 `MYNET_HISTORY_LIMIT` 设置为 2—10000，成功写入时清理过期版本。旧 schema 升级前自动创建同目录 `.before-v1-*` 一致性备份；这些文件不自动清理。历史保留不能代替独立备份。

## 检测

```powershell
npm test
npm run check:data
```

测试使用临时数据库，不修改个人数据库。覆盖隶属成环、属性目标约束、属性起点、多关系与重复关系、数据库重启持久化、并发版本冲突、失败原子性、备份导出与静态文件访问边界。

2026-11-02 的 0.1.1 已完成 4 项模型/接口集成测试及审核浏览器回归，覆盖 HTML 注入防御、一次性迁移、失败草稿、连续编辑焦点、幂等与超时等。详情见 [修复记录](docs/reviews/FIX_REVIEW_2026-11-02.md)。手机、Firefox、Safari、远程部署和大规模数据压测尚未执行。

浏览器回归命令为 `npm run test:browser`。默认查找可用的 `playwright` 模块及其浏览器；也可通过 `MYNET_PLAYWRIGHT_MODULE` 指定已安装模块的 `index.mjs` 绝对路径、`MYNET_CHROME` 指定 Chrome 可执行文件。脚本在仓库 `tests/regression.browser.mjs`，不依赖会话临时脚本。全部写入均使用临时库。

## 实现与边界

- `server.mjs`：本地 HTTP 服务、SQLite 快照事务和静态资源白名单。
- `lib/model.mjs`：服务端数据结构与关系校验。
- `storage.js`：数据库加载、保存、旧浏览器数据导入、刷新提示。
- `manage.html`、`starmap.html`：沿用原型界面与 Canvas 交互，增加异步启动和真实保存状态。
- `data.js`：初始内容与离线原型接口，原有真实初始数据未改动。

不新增文档尚未定义的跨星域关系、降格、回收站或任务排期规则。直接双击 HTML 仍为浏览器本地存储的原型模式；正式开发使用 `npm start`，不再使用 Python 静态服务。若后续发布，须按根目录发布审核记录和用户部署确认规则另行准备。
